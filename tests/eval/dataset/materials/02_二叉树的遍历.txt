# 二叉树的遍历

遍历指按某种次序访问树中每个结点恰好一次。

## 一、前序遍历（先根遍历）
顺序：根结点 → 左子树 → 右子树。
示例：对根 A、左子 B、右子 C 的二叉树，前序序列为 A B C。

## 二、中序遍历
顺序：左子树 → 根结点 → 右子树。
示例：对根 A、左子 B、右子 C 的二叉树，中序序列为 B A C。
在二叉搜索树中，中序遍历可以得到从小到大的有序序列。

## 三、后序遍历
顺序：左子树 → 右子树 → 根结点。
示例：对根 A、左子 B、右子 C 的二叉树，后序序列为 B C A。

## 四、层序遍历
按层从上到下、每层从左到右访问，通常借助队列实现。

## 五、由遍历序列还原树
已知中序序列，再给出前序或后序序列，可以唯一确定一棵二叉树；
只有前序和后序序列则不能唯一确定。
