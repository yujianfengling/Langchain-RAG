# 二叉树：定义与性质

## 一、定义
二叉树是每个结点最多有两棵子树的树结构，并且子树有左右之分，次序不能颠倒。
二叉树可以为空树。

## 二、基本术语
- 根结点：树的最上层结点。
- 左子树 / 右子树：根结点下面挂的两棵子树，位置固定。
- 叶子结点：没有子树的结点。
- 结点的度：该结点拥有的子树数目，二叉树中取值为 0、1 或 2。

## 三、重要性质
1. 在二叉树的第 i 层上至多有 2^(i-1) 个结点（i >= 1）。
2. 深度为 k 的二叉树至多有 2^k - 1 个结点（k >= 1）。
3. 对任意一棵二叉树，若叶子结点数为 n0，度为 2 的结点数为 n2，则 n0 = n2 + 1。
4. 具有 n 个结点的完全二叉树的深度为 floor(log2 n) + 1。

## 四、特殊形态
- 满二叉树：每一层的结点数都达到最大。
- 完全二叉树：除最后一层外每层都满，且最后一层的结点集中在左侧。
- 斜树：所有结点都只有左子树（或只有右子树），退化成线性结构。
