### 3. 功能实现

#### 3.1 文档类型检测
- 文本文档：默认类型
- 图像文档：通过 metadata 中的 `image_path`、`original_path` 或 `file_type` 检测
- 表格文档：通过 metadata 中的 `source` 字段或内容特征检测

#### 3.2 文档增强逻辑
- **文本文档**：只添加 `modality: "text"` 字段
- **图像文档**：
  - 添加 `modality: "image"` 字段
  - 如果缺少描述和 OCR，调用 VisionProvider 获取
  - 更新 page_content 包含视觉分析结果
- **表格文档**：
  - 添加 `modality: "table"` 字段
  - 规范化表格内容（dict → Markdown，str → 直接使用，空 → fallback）

#### 3.3 VisionProvider 集成
- 支持自动初始化 MultimodalService
- 支持依赖注入自定义 VisionProvider
- 错误处理：VisionProvider 错误不影响文档增强流程
