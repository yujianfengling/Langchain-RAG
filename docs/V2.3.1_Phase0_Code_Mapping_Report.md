### 4.5 VisionProvider 封装建议

**当前状态**: `services/model_service.py` 已有 `ModelProvider` 抽象基类和 `QwenVisionProvider` 实现。

**V2.3.1 设计**: 需要在 `rag/enrichment/` 中创建新的 `VisionProvider` 抽象接口。

**封装方案**:
```python
# rag/enrichment/multimodal_enricher.py

class VisionProvider(ABC):
    """视觉增强提供者抽象接口"""
    @abstractmethod
    def analyze_image(self, image_path: str) -> Dict[str, Any]:
        pass

class QwenVisionProvider(VisionProvider):
    """Qwen Vision 提供者实现"""
    def __init__(self, timeout: int = 120):
        self.timeout = timeout
        self._service = None
    
    def _load_service(self):
        if self._service is None:
            from services.multimodal_service import MultimodalService
            self._service = MultimodalService()
    
    def analyze_image(self, image_path: str) -> Dict[str, Any]:
        self._load_service()
        result = self._service.extract_text_from_image(image_path)
        return {
            "description": result.get("description", ""),
            "ocr_text": result.get("ocr_text", ""),
            "model_used": result.get("model_used", "")
        }
```

## 6. 风险检查

### 6.1 循环依赖风险

**风险等级**: 🟢 低

**分析**:
```
rag/enrichment/multimodal_enricher.py
  └── 依赖 services/multimodal_service.py (通过 QwenVisionProvider)

services/multimodal_service.py
  └── 依赖 services/model_service.py
  └── 依赖 rag/multimodal/image/extractor.py (OCR fallback)

rag/loaders/pdf_loader.py
  └── 依赖 rag/enrichment/multimodal_enricher.py (新增)
  └── 依赖 rag/multimodal/pdf/extractors/image_extractor.py
```

**结论**: 无循环依赖。依赖方向清晰：`rag → services`。

### 6.2 rag → services 依赖方向

**当前状态**: 
- `rag/rag_service.py` → `services/multimodal_service.py` (通过 MultimodalDocumentConverter)
- `rag/multimodal/document_converter.py` → `services/multimodal_service.py`

**V2.3.1 新增**:
- `rag/enrichment/multimodal_enricher.py` → `services/multimodal_service.py` (通过 QwenVisionProvider)

**结论**: 依赖方向合理，`rag` 模块可以依赖 `services` 模块。

### 6.3 enrichment 层位置

**建议位置**: `rag/enrichment/`

**理由**:
1. 独立于 PDF 处理流程，未来支持 Word/PPT/图片上传
2. 不属于 `rag/multimodal/pdf/`（PDF 专属）
3. 不属于 `rag/multimodal/`（已有 image/pdf 子目录）
4. 作为 rag 模块的子目录，符合模块化设计

**目录结构**:
```
rag/
  ├── enrichment/           # 新增
  │   ├── __init__.py
  │   └── multimodal_enricher.py
  ├── loaders/
  ├── multimodal/
  └── ...
```

### 6.4 其他风险

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| ImageExtractor 批量接口不兼容 | 低 | 需要修改 ImageExtractor | 在 PdfLoader 层实现批量逻辑，不修改 ImageExtractor |
