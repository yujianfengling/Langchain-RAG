## 实现细节

### 1. PdfLoader 修改

**文件**: `rag/loaders/pdf_loader.py`

**主要更改**:
1. 添加 `MultimodalEnricher` 初始化和延迟加载属性
2. 在 `_load_with_new_architecture` 方法中集成增强器调用
3. 增加错误处理，确保增强失败时降级到原始文档

**关键代码**:
```python
# 在 _load_with_new_architecture 方法中
documents = self.adapter.adapt(elements, file_path)

if not documents:
    logger.warning(f"文档转换失败: {file_path}")
    return self._load_with_legacy_architecture(file_path)

# 使用 MultimodalEnricher 增强文档
try:
    documents = self.enricher.enrich(documents)
    logger.info(f"文档增强完成: {len(documents)} 个文档")
except Exception as e:
    logger.warning(f"文档增强失败，保留原始文档: {str(e)}")
    # 增强失败时保留原始文档
```

**增强器属性**:
```python
@property
def enricher(self):
    """获取多模态文档增强器（延迟加载）"""
    if self._enricher is None:
        from ..enrichment import MultimodalEnricher
        self._enricher = MultimodalEnricher()
    return self._enricher
```

### 2. 生产流程集成

**完整流程**:
```
PDF
 ↓
PDFAnalyzer → elements
 ↓
ImageExtractor → 提取图片（可选）
 ↓
DocumentAdapter → documents
 ↓
MultimodalEnricher → enriched documents
 ↓
Document（最终）
 ↓
Embedding
```

**关键特性**:
1. **延迟加载**: MultimodalEnricher 只在需要时实例化
2. **错误处理**: 增强失败时保留原始文档，不影响 PDF 加载
3. **兼容性**: 保持与旧架构的向后兼容
4. **日志记录**: 记录增强过程的关键信息
