## FIX-001｜6 个 E2E 验收脚本一启动就崩（`Cannot access 'page' before initialization`）

- 发现时间 / 发现人：2026-09-27，试用准备期自查（准备给项目组演示"怎么跑验收脚本"时发现）
- 现象：运行脚本后立即退出，报
  `ReferenceError: Cannot access 'page' before initialization`，连浏览器都没打开。
- 复现步骤：
  1. `node tests/e2e_voice_flow.js`
  2. 立即报上面的错（`e2e_teacher_flow.js` / `e2e_model_default.js` / `e2e_agent_flow.js` / `e2e_browser_check.js` / `e2e_real_flow.js` 同样）
- 影响范围：**6 个脚本全部无法运行**。这是试用/验收要用的工具链，属阻断；
  不影响线上功能本身（后端、前端都正常）。数据无影响。
- 根因：隔离闸门 `requireBackendIsolated(page, base, purpose)` 被放在 IIFE 第一行调用，
  但它接收 `page` 参数，而 `page` 是后面才用 `const` 声明的 → 暂时性死区（TDZ）直接抛错。
  （闸门是上一轮为"写入前拒绝"加的，当时只验证了 Python 脚本，没有实际跑过这 6 个 JS 脚本。）
- 修复：闸门改为不依赖 Playwright —— 用 Node 的 `fetch` 直接查 `/api/health`
  （`async function requireBackendIsolated(base, purpose)`），调用点去掉 `page` 参数。
  6 个文件同步修改。
- 回归结果：
  - 语法：6 个文件 `node --check` 全部通过；
  - 闸门仍有效：把脚本指向一个返回 `isolated:false` 的假后端 → **退出码 2**，打印"拒绝执行：…（正式目录）"；
  - 真实跑通：`tests/e2e_voice_flow.js` 在桌面 1440×1000 下 **22/22 通过**、在 390×844 下 **24/24 通过**；
    其余 5 个脚本可正常启动（本轮未逐一做全流程验收）。
- 未覆盖/遗留：其余 5 个脚本只验证了"能启动+闸门有效"，没有重跑它们的完整断言（不在本轮范围）。

## FIX-002｜语音验收脚本在手机宽度下点不到入口（脚本适配，非产品缺陷）

- 发现时间 / 发现人：2026-09-27，手机端语音实测时
- 现象：390×844 下脚本第一步就超时：`waiting for locator('button:has-text("登录 / 注册")')`
  （匹配到 2 个：侧边栏里隐藏的那个 + 顶栏里可见的那个，脚本取到了隐藏的）；
  后段又在"切换会话"处超时（窄屏聊天区顶部是「新建」，宽屏侧栏是「新建对话」）。
- 复现步骤：
  1. `node tests/e2e_voice_flow.js http://localhost:3000 <假麦克风wav> 390 844`
  2. 第一步登录点击超时
- 影响范围：仅影响**自动化脚本**在窄屏下的运行；真实用户在手机上点顶栏按钮是正常的
  （已在响应式走查中实测）。不影响产品功能与数据。
- 根因：脚本按桌面布局写死了选择器；窄屏改了信息架构（顶栏 + 抽屉）后选择器失配。
- 修复：`tests/e2e_voice_flow.js` 增加视口参数（第 4、5 个参数）与窄屏分支：
  登录入口走 `.app-topbar`；进页面先开抽屉；"新建会话"按钮用 `新\s*建\s*(对话)?` 兼容两种文案。
- 回归结果：
  - 390×844：**24/24 通过**（含录音按钮、朗读开关在可视区内的两条专项检查）
  - 1440×1000 对照：**22/22 通过**（桌面行为未变）
- 未覆盖/遗留：真机（真实手机/麦克风/扬声器、iOS Safari/Android Chrome）仍未验证。

## 运维观察（不是代码缺陷，但试用期间会碰到）

### OBS-001｜本地语音服务并发排队 → `POST /api/audio/tts` 502
- 现象：连续多次点朗读时出现 `语音合成不可用：本地语音服务失败（语音服务正忙（等待超过 20 秒）…）`，
  同时错误文案里提到 MiMo 语音回退失败（外部凭证不可用）。
- 复现：短时间内连续触发多次合成（脚本连跑两轮即出现）；**服务空闲后重跑全部通过**。
- 结论：本地 CosyVoice 单实例排队所致，**不是手机端或前端缺陷**；回退链路当前不可用，不应依赖。
- 试用建议：一次只让一个学生点朗读；出现该提示时稍等再点，文字问答不受影响。
