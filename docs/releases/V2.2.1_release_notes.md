# V2.2.1 Release Notes

## 版本信息

## 核心功能

### 1. 混合检索增强生成 (Hybrid RAG)
- **FAISS 向量检索**: 基于 Sentence-Transformers 的语义相似度检索
- **BM25 关键词检索**: 基于 Rank-BM25 的精确关键词匹配
- **Rerank 重排序**: 对检索结果进行相关性重排序，提升准确率

### 2. 多格式知识库支持
- **文档格式**: PDF、DOCX、TXT、Markdown
- **图片格式**: JPG、JPEG、PNG、WEBP
- **自动处理**: 文本分割、向量化、索引构建

### 3. 多模态图片理解
- **Qwen-VL 视觉模型**: 阿里云通义千问视觉模型，理解图片内容
- **OCR 文字提取**: 基于 pytesseract 的备用方案
- **图片描述生成**: 自动生成图片描述文档，纳入 RAG 检索

### 4. 模型支持与切换
- **小米 MiMo**: 默认文本模型，已内置 API 密钥
- **DeepSeek**: 可切换模型，已内置 API 密钥
- **通义千问**: 需用户配置 API 密钥
- **通义千问视觉**: 图片理解专用模型
- **实时切换**: 前端支持模型下拉菜单切换

### 5. 完整 API 体系
- **知识库管理**: 创建、构建、删除、统计、文档管理
- **学科管理**: 学科列表、创建、删除
- **模型管理**: 模型状态、可用模型、切换提供商
- **教育功能**: 批量批改、教育数据分析
- **SSE 流式响应**: 实时流式问答

## 重要 Bug 修复

### 1. Unicode Surrogate 导致 PDF Embedding 失败
- **问题**: PDF 文本中包含 Unicode surrogate 字符（如 `\ud800`），导致 Sentence-Transformers 编码失败
- **修复**: 在文本预处理阶段过滤 surrogate 字符，确保编码安全

### 2. Chat 参数兼容问题
- **问题**: API 路由传递 `image_data`/`image_mime_type` 参数，但 `chat_service` 函数签名不支持
- **修复**: 更新 `chat_with_ai()` 和 `chat_stream()` 函数签名，支持图片参数

### 3. SSE 流式响应格式问题
- **问题**: `chat_stream()` 返回字典对象，但 `StreamingResponse` 需要字符串
- **修复**: 添加 `sse_generator()` 包装器，将字典转换为 `data: {json}\n\n` 格式

### 4. 图片缓存和安全限制
- **图片缓存**: 基于文件 MD5 的 JSON 缓存，30 天过期
- **尺寸限制**: 最大 4096px，最大 4M 像素
- **错误处理**: 区分超时/认证/配额/通用错误，返回用户友好信息

### 5. 日志增强
- **格式**: `[Multimodal]` 前缀，包含 image/size/model/latency/caption_length/fallback 信息

## 已知限制

### 1. API 密钥配置
- **小米 MiMo**: 已内置，开箱即用
- **DeepSeek**: 已内置，开箱即用
- **通义千问**: 需要用户自行配置 API 密钥
- **配置方式**: 创建 `.env` 文件，参考 `config/env.example`

### 2. 模型下载
- **HuggingFace 模型**: Sentence-Transformers 模型可能需要镜像源
- **解决方案**: 设置环境变量 `HF_ENDPOINT=https://hf-mirror.com`

### 3. 系统要求
- **Python**: 3.10+
- **Node.js**: 16+
- **内存**: 大文档处理可能需要较多内存
- **存储**: 向量索引和 BM25 索引需要存储空间

### 4. 平台兼容性
- **Windows**: FAISS 可能需要 `faiss-cpu` 版本
- **Linux/macOS**: 默认支持

### 5. 文档大小限制
- **文本分割**: 默认 chunk_size=500, chunk_overlap=50
- **大文档**: 可能需要调整配置以避免内存不足
