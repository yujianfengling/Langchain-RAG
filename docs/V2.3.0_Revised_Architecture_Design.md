# V2.3.0 Revised Architecture Design

## 一、当前架构问题分析

### 1.1 rag/document.py 职责过重

当前 `rag/document.py` 包含了所有文件类型的加载逻辑：

```
PDF/DOCX/TXT/MD/图片
        ↓
Document (单一入口)
```

**问题**：
- 违反单一职责原则
- 难以维护和扩展
- 添加新文件类型需要修改核心代码

### 1.2 PDF处理逻辑过于简单

当前 PDF 加载只是简单的文本提取：

```python
# 当前实现
def _load_pdf(self, file_path: str) -> List[Document]:
    doc = fitz.open(file_path)
    full_text = ""
    for page in doc:
        full_text += page.get_text()
    # ... 只提取文本，忽略图片/公式/表格
```

**问题**：
- 无法识别图片、公式、表格等元素
- 无法提取元素的位置信息
- 无法进行元素级别的处理

### 1.3 MultimodalDocument 协议不统一

当前 `MultimodalDocument` 主要针对图片设计：

```python
@dataclass
class MultimodalDocument:
    content: str
    source: str
    modality: str  # "image", "pdf", "audio", "video"
    width: int = 0           # 图片特有
    height: int = 0          # 图片特有
    format: str = ""         # 图片特有
    # ...
```

**问题**：
- 字段设计偏向图片模态
- 无法表示 PDF 中的公式、表格等元素
- 缺乏统一的内容类型枚举

### 1.4 缺乏中间数据层

当前从 PDF 直接生成 Document：

```
PDF → fitz.open → 文本提取 → Document
```

**问题**：
- 没有中间表示层
- 无法进行元素级别的处理
- 不利于后续扩展（音频/视频）

## 二、新架构设计

### 2.1 核心设计原则

1. **单一职责**：每个模块只负责一件事
2. **开闭原则**：对扩展开放，对修改关闭
3. **依赖倒置**：依赖抽象，不依赖具体实现
4. **接口隔离**：提供最小必要的接口

### 2.2 新的目录结构

```
rag/
├── document.py              # 路由层（只做类型判断和分发）
├── loaders/                 # 文件加载器
│   ├── __init__.py
│   ├── base.py              # Loader 基类
│   ├── pdf_loader.py        # PDF 加载器
│   ├── docx_loader.py       # DOCX 加载器
│   ├── txt_loader.py        # TXT 加载器
│   ├── md_loader.py         # Markdown 加载器
│   └── image_loader.py      # 图片加载器
├── multimodal/              # 多模态处理
│   ├── __init__.py
│   ├── base.py              # 基础类（MultimodalDocument）
│   ├── document_converter.py # 文档转换器
│   ├── vision_providers/    # 视觉模型
│   └── pdf/                 # PDF 专用处理
│       ├── __init__.py
│       ├── analyzer.py      # PDF 元素分析器
│       ├── extractor.py     # 元素提取器
│       ├── models.py        # 数据模型
│       └── adapters.py      # 文档适配器
├── embedder.py
├── graph.py
├── processor.py
└── store.py
```

### 2.3 新的处理流程

```
文件输入
    ↓
DocumentRouter (document.py)
    ↓
对应Loader (loaders/)
    ↓
[对于PDF]
    ↓
PDFAnalyzer (multimodal/pdf/analyzer.py)
    ↓
List[PDFElement] (中间数据层)
    ↓
DocumentAdapter (multimodal/pdf/adapters.py)
    ↓
List[Document]
```

## 三、数据结构设计

### 3.1 PDFElement 中间数据层

```python
from enum import Enum
from dataclasses import dataclass, field
from typing import Any, Dict, Optional, Tuple


class PDFElementType(Enum):
    """PDF元素类型"""
    TEXT = "text"
    IMAGE = "image"
    FORMULA = "formula"
    TABLE = "table"


@dataclass
class BoundingBox:
    """边界框"""
    x0: float
    y0: float
    x1: float
    y1: float
    
    @property
    def width(self) -> float:
        return self.x1 - self.x0
    
    @property
    def height(self) -> float:
        return self.y1 - self.y0
    
    @property
    def area(self) -> float:
        return self.width * self.height


@dataclass
class PDFElement:
    """PDF元素中间表示"""
    type: PDFElementType
    content: Any  # str (文本/公式), bytes (图片), List[List[str]] (表格)
    page: int
    bbox: Optional[BoundingBox] = None
    confidence: float = 1.0
    metadata: Dict[str, Any] = field(default_factory=dict)
    
    def to_dict(self) -> Dict[str, Any]:
        """转换为字典"""
        return {
            "type": self.type.value,
            "content": self.content if not isinstance(self.content, bytes) else f"[binary:{len(self.content)} bytes]",
            "page": self.page,
            "bbox": {
                "x0": self.bbox.x0,
                "y0": self.bbox.y0,
                "x1": self.bbox.x1,
                "y1": self.bbox.y1
            } if self.bbox else None,
            "confidence": self.confidence,
            "metadata": self.metadata
        }
```

### 3.2 统一 MultimodalDocument 协议

```python
from enum import Enum
from dataclasses import dataclass, field
from typing import Any, Dict, Optional


class Modality(Enum):
    """模态类型"""
    TEXT = "text"          # 纯文本
    IMAGE = "image"        # 图片
    PDF = "pdf"           # PDF文档
    AUDIO = "audio"        # 音频
    VIDEO = "video"        # 视频


class ContentType(Enum):
    """内容类型"""
    TEXT = "text"          # 文本内容
    IMAGE = "image"        # 图片内容
    FORMULA = "formula"    # 公式内容
    TABLE = "table"        # 表格内容
    MIXED = "mixed"        # 混合内容


@dataclass
class MultimodalDocument:
    """统一多模态文档协议"""
    # 核心标识
    modality: Modality
    content_type: ContentType
    
    # 内容
    content: str  # 文本内容或描述
    raw_content: Optional[bytes] = None  # 原始二进制内容（图片/音频/视频）
    
    # 来源信息
    source: str = ""
    
    # 通用元数据
    metadata: Dict[str, Any] = field(default_factory=dict)
    
    # === 通用字段 ===
    description: str = ""
    
    # === 文本相关 ===
    char_count: int = 0
    word_count: int = 0
    language: str = "en"
    
    # === 位置信息（PDF/文档） ===
    page: Optional[int] = None
    bbox: Optional[Dict[str, float]] = None  # {x0, y0, x1, y1}
    
    # === 模型信息 ===
    model_used: Optional[str] = None
    confidence: float = 1.0
    
    def __post_init__(self):
        """初始化后处理"""
        if self.content and not self.char_count:
            self.char_count = len(self.content)
        if self.content and not self.word_count:
            self.word_count = len(self.content.split())
    
    @property
    def is_multimodal(self) -> bool:
        """是否多模态"""
        return self.modality != Modality.TEXT
    
    @property
    def content_length(self) -> int:
        """内容长度"""
        return len(self.content) if self.content else 0
    
    def get_embedding_text(self) -> str:
        """获取用于embedding的文本"""
        return self.content
    
    def to_dict(self) -> Dict[str, Any]:
        """转换为字典"""
        return {
            "modality": self.modality.value,
            "content_type": self.content_type.value,
            "content": self.content[:500] + "..." if len(self.content) > 500 else self.content,
            "source": self.source,
            "description": self.description,
            "char_count": self.char_count,
            "word_count": self.word_count,
            "language": self.language,
            "page": self.page,
            "bbox": self.bbox,
            "model_used": self.model_used,
            "confidence": self.confidence,
            "metadata": self.metadata
        }
```

### 3.3 Loader 基类

```python
from abc import ABC, abstractmethod
from typing import List, Optional
from dataclasses import dataclass


@dataclass
class LoadResult:
    """加载结果"""
    documents: List['Document']
    success: bool
    error_message: Optional[str] = None
    metadata: dict = None
    
    def __post_init__(self):
        if self.metadata is None:
            self.metadata = {}


class BaseLoader(ABC):
    """加载器基类"""
    
    @abstractmethod
    def can_load(self, file_path: str) -> bool:
        """判断是否能加载该文件"""
        pass
    
    @abstractmethod
    def load(self, file_path: str) -> LoadResult:
        """加载文件"""
        pass
    
    @abstractmethod
    def get_supported_extensions(self) -> List[str]:
        """获取支持的文件扩展名"""
        pass
```

## 五、技术方案要点

### 5.1 PDF 元素检测策略

| 元素类型 | 检测方法 | 置信度阈值 |
|---------|---------|-----------|
| **文本** | PyMuPDF 文本块分析 | 0.9 |
| **图片** | PyMuPDF 图片对象检测 | 0.95 |
| **表格** | pdfplumber 表格检测 | 0.8 |
| **公式** | 启发式规则（特殊字符、位置） | 0.7 |

### 5.2 性能优化策略

1. **并行处理**：多页并行分析
2. **缓存机制**：L1 内存 + L2 磁盘
3. **流式处理**：大文件分块处理
4. **断点续传**：支持中断后继续

### 5.3 成本控制策略

1. **调用限制**：每 PDF 100 次，每日 1000 次
2. **缓存复用**：基于 MD5 hash 的缓存
3. **批量处理**：合并多个请求
4. **降级策略**：失败时使用简单方法

### 5.4 兼容性保障

1. **向后兼容**：现有接口不变
2. **渐进增强**：新功能可选启用
3. **降级机制**：依赖缺失时自动降级
4. **配置驱动**：通过配置控制行为
