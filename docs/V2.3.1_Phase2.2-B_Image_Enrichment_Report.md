## 实现内容

### 1. 修改文件

#### 1.1 `rag/enrichment/multimodal_enricher.py`

**修改方法**：`_enrich_image_document()` 方法

**主要变更**：
1. **添加 modality 检查**：`metadata["modality"] == "image"` 才进行增强
2. **获取 image_path**：从 `metadata["image_path"]` 获取图片路径
3. **调用 VisionProvider**：`VisionProvider.analyze_image(image_path)`
4. **写回 metadata**：
   - `description`：图片描述
   - `ocr_text`：OCR 文字
   - `model_used`：模型名称（默认 "qwen-vision"）
5. **更新 page_content**：
   - 格式：`图片描述:\nxxx\n\nOCR:\nxxx`
   - 保留原有内容（如果不是占位符）
6. **错误处理**：Vision 失败或异常时保留原 Document

**修改方法**：`_update_page_content_with_vision()` 方法

**主要变更**：
1. **新格式**：`图片描述:\nxxx` 和 `OCR:\nxxx`
2. **保留原有内容**：如果不是占位符，保留原有内容

### 2. 错误处理

#### 2.1 VisionProvider 返回错误
```python
if vision_result.get("error"):
    logger.warning(f"VisionProvider分析图像失败: {vision_result['error']}")
    return doc  # 保留原Document
```

#### 2.2 VisionProvider 异常
```python
except Exception as e:
    logger.warning(f"调用VisionProvider失败: {e}")
    return doc  # 保留原Document
```

#### 2.3 image_path 不存在
```python
if not image_path:
    logger.warning("图像文档缺少image_path，跳过增强")
    return doc
```

### 3. page_content 更新逻辑

#### 3.1 新格式
```python
content_parts = []
if description:
    content_parts.append(f"图片描述:\n{description}")
if ocr_text:
    content_parts.append(f"OCR:\n{ocr_text}")
```

#### 3.2 保留原有内容
```python
if content_parts:
    original_content = doc.page_content
    if original_content and not original_content.startswith("[图片]"):
        content_parts.insert(0, original_content)
    
    doc.page_content = "\n\n".join(content_parts)
```
