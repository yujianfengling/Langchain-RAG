## 1. 问题诊断

### 1.1 根本原因

V2.3.1 Final Validation发现Image Document全部缺少关键字段：
- `image_path`
- `description`
- `ocr_text`
- `model_used`

**根因分析**：

1. **ImageExtractor接口不匹配**
   - `pdf_loader.py` 调用 `extract_images(image_elements, file_path)`
   - 实际 `ImageExtractor` 类只有 `extract` 和 `extract_all` 方法
   - 接口不匹配导致图片提取流程中断

2. **PDFElement缺少image_path**
   - `ImageDetector` 生成的 `PDFElement.content` 只有图片元数据
   - 包含：`xref`, `index`, `width`, `height`, `colorspace`, `bpc`
   - 不包含：`image_path`

### 1.2 数据流断点

```
PDFAnalyzer → [PDFElement] → ImageExtractor → [PDFElement] → ImageAdapter → [Document] → MultimodalEnricher → [Document]
     |              |              |              |              |              |              |              |
   正常         缺少image_path    接口不匹配      未执行         依赖image_path    未执行         依赖modality    未执行
```

### 2.2 具体修改

#### 2.2.1 `rag/loaders/pdf_loader.py`

**修改前**：
```python
def _extract_images_from_elements(self, elements: list, file_path: Path) -> list:
    # ...
    image_paths = self.image_extractor.extract_images(image_elements, file_path)
    # ...
```

**修改后**：
```python
def _extract_images_from_elements(self, elements: list, file_path: Path) -> list:
    # ...
    # 使用 ImageExtractor 提取图片
    # 调用 extract_all 方法，参数顺序为 (pdf_path, image_elements)
    image_paths = self.image_extractor.extract_all(file_path, image_elements)
    
    # 按页面分组图片元素
    page_groups = {}
    for element in image_elements:
        page_num = element.page
        if page_num not in page_groups:
            page_groups[page_num] = []
        page_groups[page_num].append(element)
    
    # 按页面顺序映射路径
    path_index = 0
    enhanced_dict = {}
    for page_num in sorted(page_groups.keys()):
        page_elements = page_groups[page_num]
        for element in page_elements:
            if path_index < len(image_paths):
                # 为元素添加 image_path
                element.content['image_path'] = str(image_paths[path_index])
                element.content['extraction_method'] = 'image_extractor'
                enhanced_dict[element.content.get('xref')] = element
                path_index += 1
    # ...
```
