## 一、报告矛盾分析

### 矛盾1: 摘要"正常时图片检索100%命中" vs 详细检查点6记录0/3

**根本原因**: Phase 2.4.2的"100%命中"是基于Vision API**正常工作时**的预期推断，非实际测试统计。
检查点6的0/3是在API间歇性超时条件下执行的实际结果。两者不矛盾，是API稳定性的不同表现。

### 矛盾2: extract_all返回路径数0 vs 最终有效image_path=1

**根本原因**: `extract_all()`返回的是本轮**新提取**的文件数。ImageExtractor写入前检查MD5缓存，
文件已存在则直接返回路径，不计入新提取。因此：新提取=0，缓存命中=1，最终有效路径=1。

### 统计数据分离

| 指标 | 值 | 说明 |
|------|-----|------|
| image元素总数 | 1 | PDFAnalyzer检测 |
| 本次新提取图片数 | 0 | 缓存命中，无需重新写入 |
| 已有图片缓存命中数 | 1 | 文件已存在 |
| 最终有效image_path数 | 1 | metadata中记录的路径 |
| Vision新调用数 | 1 | 本次API调用成功 |
| Vision缓存命中数 | 0 | 无缓存（首次调用） |
