# 演示与部署指南（从启动到"教师查看学情"）

> 更新时间：2026-09-27
> 目标：新成员照着这份文档，能从零启动服务并走通一条完整的师生演示路径。
> 首次启动前**先跑自检**：`python tests/check_first_run.py`（只读，不会在目标目录建表）

> ⛔ **对外部署/公开演示之前必须完成的阻塞项：轮换历史密钥。**
> 真实密钥曾出现在历史提交中（详见 `docs/CREDENTIALS.md`），**必须由密钥持有人登录供应商后台更换**；
> 在真正更换之前，任何文档与汇报里都**不能写"密钥已轮换"**。本地课堂演示不受此影响。

- 5–8 分钟现场演示路线（讲什么、怎么对比普通 AI 问答）：`docs/DEMO_SCRIPT.md`
- 演示数据准备（一条命令建好演示账号与班级，数据带「(演示数据)」标注）：`tests/seed_demo_data.py`
- 首次使用体验走查结论与已知局限：`docs/FIRST_USE_REVIEW.md`

## 一、首次启动（约 15 分钟，含模型下载）

### 1. 自检

```powershell
cd E:\WORKBUDDY\Game\git_text
python tests\check_first_run.py
```

自检会逐项告诉你缺什么、怎么补（Python 版本 / 依赖 / 数据目录可写 / 数据库初始化 /
文本模型密钥 / 历史知识库 / 本地语音栈）。退出码 0 表示必需项齐全。

> 自检**不会在目标数据目录建表或写业务数据**：数据库初始化只在临时目录里试跑一遍后清理。
> 它只以只读方式报告目标目录里已存在哪些库。

### 2. 配置

```powershell
copy config\env.example .env
#  必填：DEEPSEEK_API_KEY=<你的密钥>
#  可选：LLM_MODEL（默认 deepseek）、TEACHER_USERS / ADMIN_USERS（见下）
```

**首次部署必须指定至少一位教师或管理员**——创建课程不再自动授予教师身份：

```ini
# .env 里（或用系统环境变量）
TEACHER_USERS=your_teacher_account      # 逗号分隔；这些账号登录后即为教师
ADMIN_USERS=your_admin_account          # 管理员：可开通教师、生成教师邀请码
```

其他账号想成为教师，两条路：**管理员**生成**教师邀请码**，对方在「设置 → 教师身份」输入；
或由管理员直接开通。

> 邀请码默认**只有管理员能签发**。若确实需要让教师自己拉人，再额外设置
> `TEACHER_CAN_INVITE=1`（可用 `TEACHER_ISSUE_QUOTA` 调名下未用尽邀请码上限、
> `TEACHER_ISSUE_MAX_TTL_DAYS` 调有效期上限）。不开这个开关时，教师端「生成邀请码」
> 按钮为禁用状态并说明原因，接口层面也会拒绝（403），不会出现"按钮能点但报错"的困惑。

### 3. 启动

```powershell
# 终端一：后端
python -m uvicorn api.app:app --host 127.0.0.1 --port 8000

# 终端二：前端
cd frontend; npm install; npm run dev

# 终端三（可选，语音功能才需要）
$env:SPEECH_STACK_DIR="E:\WORKBUDDY\Game\speech_stack"
E:\WORKBUDDY\Game\speech_stack\venv\Scripts\python.exe -m speech_service.server
```

访问 http://localhost:3000 ，健康检查 `/api/health`（含各能力可用性与不可用原因）。

### 4. 缺东西时的表现（不会静默失败）

| 缺失 | 表现 |
|---|---|
| 文本模型密钥 | `/api/health` 的 `capabilities.text.available=false` 并给出原因；问答接口返回可读错误 |
| 本地语音模型/服务未启动 | `local_asr/local_tts.available=false`；**文字问答、学习闭环完全不受影响** |
| 知识库未构建 | 教师端课程详情显示 `knowledge_base.available=false` 与原因；资料页有「重建知识库」按钮与失败原因 |
| 教师未开通 | 建课返回 403 与提示"需要教师邀请码"，设置页有开通入口 |

## 二、演示脚本（照着做，约 10 分钟）

### 第 1 步 教师开通与建课

1. 用 `TEACHER_USERS` 里的账号登录（或用管理员账号生成邀请码 → 另一账号在「设置 → 教师身份」输入）。
2. 左侧出现 **教师工作台** → 「我的课程」→ 新建课程（如 `数据结构（演示）`）。
   系统会为该课程创建**独立知识库**；左侧菜单同时出现「课程与班级 / 课程资料 / 教案 / 作业与练习 / 学情分析」。

### 第 2 步 建班级、拿邀请码

3. 进「课程与班级」→ 新建班级（如 `周一班`）→ 页面显示 **6 位邀请码**（可复制、可轮换、可撤销，并显示有效期与已用次数）。

### 第 3 步 上传资料并建知识库

4. 进「课程资料」→ 上传讲义（示例材料可用 `tests/eval/dataset/materials/*.txt`）→
   **上传后系统会自动构建课程知识库**，等提示变成「课程知识库可用（已收录 N 份文档）」即可；
   若自动构建失败，界面会给出原因，可再手动点「重建知识库」。
5. 把「教师草稿」类资料设为 **仅教师可见**（演示隔离：学生看不到也下载不到）。

### 第 4 步 写教案并发布

6. 进「教案」→ 填主题、课时、教学目标、选择班级 → **生成教案草稿**（真实模型，会列出依据的课程资料；
   资料不足时明确提示）。
7. 修改某个区块 → 「保存为新版本」（提示 `已保存为 v2，历史版本保留`）→ 「预览」→「发布」→「导出 .md」。
8. 演示**草稿不提前公开**：发布前学生端看不到。（可先让学生看一次空列表，再发布并刷新）

### 第 5 步 发布练习

9. 进「作业与练习」→ 新建（选班级、标题、知识点、截止日期）→「AI 出题」→
   **一定要在弹窗里选择「挂到草稿作业」**（不选只会预览、不写入作业，发布的作业会是空的）→
   确认表格里「题目数」大于 0 →「发布」。（题目依据课程资料生成，**标准答案留在服务端**）
10. 发布结果会显示成功/跳过/失败人数；已发布作业不可改（避免静默改动学生的截止时间）。

### 第 6 步 学生学、问、做

11. 用学生账号登录 → 「我的学习 → 我的课程」→ 输入邀请码加入 → 看到课程与老师布置的作业。
12. 「进入作答」逐题作答（后端判分，交卷前不给答案）→ 全部作答后「标记完成」；
    任务同时出现在「今日任务」。
13. 去「AI学习助手」问 1–2 个课程问题，展示**参考来源**（引用可定位到资料）。
14. 打开「错题本」看错题，用「学习助手」生成复习安排（演示改计划会**要求确认**）。
15. （可选）点录音提问 → 转写文本进入输入框（**由学生确认后发送**）→ 回答自动朗读。

### 第 7 步 教师查看学情

16. 回到教师账号 → 「学情分析」→ 选班级与时间范围（7/30/90 天）。
17. 展示：参与人数与样本量、任务完成情况、各知识点作答（含**样本量**与"是否足以下结论"）、
    常见错题（题干与选项，无答案）、每日趋势；每块都标注**数据来源**。
18. 点「AI 解读」：样本足够时给教学建议；样本不足时明确显示"数据不足，未调用模型"。
19. 从「错误较多的知识点」下钻：错题 → 相关课程资料 → 建议动作（补资料 / 发补充练习）。

> 演示要点小结：**教师发布 → 学生学/问/做 → 判分与错题 → 掌握度与复习 → 教师学情 → 调整下一次教学**，
> 每一步的数据都是真实记录算出来的（`docs/TEACHING_EVAL.md` 有 47/47 项的自动验证）。

## 三、部署前检查清单

| 检查项 | 做法 |
|---|---|
| 密钥不进仓库 | `python -m pytest tests/test_credentials_hygiene.py -q`（扫描已跟踪文件，只报位置不打印值） |
| **对外部署前必须轮换密钥** | 见 `docs/CREDENTIALS.md`；历史提交中的旧密钥仍在远端可达（属阻塞项） |
| 权限收紧 | 配置 `KNOWLEDGE_ADMIN_USERS`（历史全局学科写权限）、`ADMIN_USERS`、`TEACHER_USERS` |
| 学生数据隔离 | 每个学生只看到自己的作答/错题/计划/会话；教师端只用汇总数据（有自动化用例覆盖） |
| 数据备份 | 迁移前复制 `data/*.db` 到 `data/backups/<时间戳>-.../`（迁移脚本可重复执行） |
| 不进仓库的内容 | `.env`、`config/local_secrets.json`、`data/`、`speech_stack/`（模型权重）、录音与合成缓存、`tests/_screenshots/`、`tests/eval/output/` 均在 `.gitignore` |

## 四、常见问题

**Q：学生登录后没有「教师工作台」菜单？**
A：正常。教师身份需受控开通（见第一节第 2 步）。前端菜单只是展示，后端也会拦住越权请求。

**Q：语音按钮点了没反应 / 报"本地语音不可用"？**
A：语音服务（:8100）未启动或模型未加载完。先 `curl http://127.0.0.1:8100/health` 看引擎状态；
不启动语音服务时，文字问答与全部学习功能照常可用。

**Q：教师端学情显示"数据不足"？**
A：样本量门槛为"已判分作答 ≥5 次且参与学生 ≥2 人"。小班或刚开始使用时先让学生完成练习。

**Q：邀请码被泄露了怎么办？**
A：教师端「课程与班级」→ 撤销邀请码（立即失效）或重置出新码；加入尝试也有频率限制（默认 10 次/10 分钟）。

**Q：学生答完作业，错题本 / 复习安排却是空的？**
A：先看右上角**学科是否选中**（现在进入页面会自动选中"我加入的课程"对应学科，切到错题本等标签也会刷新数据）。
若仍为空，确认他确实答错过（全对时错题本本来就空），以及统计的是同一个学科。

**Q：手机上能用吗？**
A：**学生端可以用**：≤900px 自动切成"顶栏 + 抽屉导航"，390px 手机宽度已实测走通
（注册/登录 → 入班 → 作答 → 错题本 → 复习 → 学习助手提问，共 134 项走查全绿）。
**教师端请用电脑**：教师工作台在 390px 下仍会横向溢出（按电脑为主设计，本轮未做手机重排）。

**Q：想重置演示数据？**
A：用隔离目录演示（`EDU_DATA_DIR`），删掉该目录即可；正式库请先备份再按 `docs/TEST_DATA_INVENTORY.md` 的方案处理。
