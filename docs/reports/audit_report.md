## 3. 已修复问题列表

### 修复 1: `.gitignore` 添加日志文件排除

**文件**: `.gitignore`  
**修改内容**: 添加 `*.log` 模式  
**修改原因**: 根目录下的 `backend.log`, `backend_err.log`, `frontend.log`, `frontend_err.log` 不应被版本控制  
**影响范围**: 仅影响 git 追踪，不影响功能

### 修复 2: `install.sh` 完善安装脚本

**文件**: `install.sh`  
**修改内容**: 添加完整的安装脚本，包括 Python 虚拟环境创建、依赖安装、目录创建、环境变量文件复制  
**修改原因**: 原文件为空，新开发者无法快速搭建环境  
**影响范围**: 仅影响新环境部署

### 修复 3: `mindmap_service.py` 使用配置系统

**文件**: `mindmap_service.py`  
**修改内容**: 将直接读取 `os.getenv()` 改为使用 `config.settings`  
**修改原因**: 保持配置管理的一致性，避免硬编码  
**影响范围**: 思维导图生成功能，行为不变

### 修复 4: `data_manager.py` 使用配置系统

**文件**: `data_manager.py`  
**修改内容**: 将硬编码路径 `data/subjects.json` 改为使用 `settings.path.data_dir`  
**修改原因**: 避免相对路径在不同工作目录下失效  
**影响范围**: 数据管理功能，行为不变

### 修复 5: `hybrid_retriever.py` 方法调用修复

**文件**: `rag/hybrid_retriever.py`  
**修改内容**: 将 `faiss_store.count` 改为 `faiss_store.count()`  
**修改原因**: `count` 是方法不是属性，缺少括号会导致返回函数对象而非数量  
**影响范围**: 混合检索器状态显示，不影响核心检索功能

### 修复 6: `rag_config.py` 默认值修复

**文件**: `config/rag_config.py`  
**修改内容**: 
- `rerank.enabled` 默认值从 `False` 改为 `True`
- `text_splitter.use_semantic_split` 默认值从 `False` 改为 `True`

**修改原因**: 与 `rag_service.py` 中的使用保持一致，启用项目核心功能  
**影响范围**: RAG 检索和文本分割功能
