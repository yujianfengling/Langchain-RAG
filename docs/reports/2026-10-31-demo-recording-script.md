## 镜头 1（约 90s）：学生资料问答 → 引用核对原页 【A 流程】

1. 浏览器 :3000，登录 `demo_student`（或用吴艺玲会话）。
2. 选择学科「验收-A流程-1031」。
3. 输入：`蓝鲸灯的出厂校准码是什么？校准周期多少天？`
   ⏱ 首字约 3–8s（冷启动首问会加载索引，先问一次热身更好）。
4. **口令点**：回答给出 `ZX-7391-QX` / `47 天`，带 `[1]` 引用。
5. 点击回答里的 `[1]` → 右栏打开「引用原文」→ 点该片段的「查看页面图」→
   弹出**页面原文**：第 1 页真实渲染，黄色高亮恰好套住校准码那一行。
   ⏱ 页面图加载 <1s（页面索引已预建）。
6. 收尾话术："回答、引用编号、原文片段、页面图片是同一个来源，学生能自己核对。"

## 镜头 2（约 60s）：知识点学习 → 练习 → 复习定位 【B 流程】

1. 左栏学习路线（「数据库」学科 18 章）：点「第6章 关系数据理论」→「函数依赖与范式」。
2. 主区出现「讲懂这个知识点 / 做一道练习」→ 点「做一道练习」⏱ 15–20s 出 3 题。
3. 作答：1 题答对（显示掌握度 %）、1 题故意答错（显示正确解释 + 掌握度下降）。
4. 切「任务与复习」→「之后安排」出现「复习：函数依赖与范式 · 错题自动安排」。
   （提前在演示前完成过一次，也可现场重做一遍，任务会合并/更新。）
5. 收尾话术："错题自动进入复习计划，掌握度来自服务端真实作答，不是模型编的。"

## 镜头 3（约 60s）：教师备课 → 发布 → 学生查看 【C 流程】

1. 退出登录 → `demo_teacher` 登录（教师工作台）。
2. 「课程与备课」→ 数据结构·演示课程 →「教案」页签 →
   打开已发布教案「栈与队列的应用场景（教师修订版）」看内容
   （教学步骤里引用了课程资料特有常数 ZETA-8642——体现"依据课程知识库"）。
   *若现场生成新教案：输入主题"栈与队列的应用场景"⏱ 30–40s，生成后 v1 草稿。*
3. 演示「编辑 → 保存为新版本」（v2 版本化）→「发布」→ 确认框「发布」。
4. 退出 → `demo_student` 登录 → 「任务与复习」→ 课程与作业 →
   数据结构·演示课程 →「已发布教案」→ 弹窗显示 v2 内容与发布日期。
5. 顺带指一下「作业与批改」入口（演示班已有 9 次作业、1 份已完成）与教师端「学情分析」
   （真实数字 + 结论门槛说明）。
6. 收尾话术："教师改的是版本化草稿，发布后学生看到的就是当前版；没发布的草稿学生看不到。"

## 录屏注意

- **不要**在录屏中同时触发生成知识图谱/全量重建（会拖慢检索响应）。
- 录音笔记（ASR）需要真麦克风，留给人工验收：伴学页「录音笔记」按钮 → 录一段 →
  转写 → 保存笔记。
- 若提问后提示"当前资料未覆盖"：那是防编造设计，换个与资料相关的问题即可；
  切勿现场换模型或重建知识库。
- 演示里 LangChain 参与的环节：文档加载/切分与 RAG 检索链（rag/ 目录基于 LangChain
  的 loader/splitter/vectorstore 抽象）；对外表述为"检索链基于 LangChain 生态 +
  自研的混合检索与预算控制"，不要说整条链路都是自研或都是 LangChain。
