## 四、能力现状（按可验证程度分级）

分级口径：**已实测**＝有真实数据/真实调用证据；**仅自动测试**＝有单测但未做端到端实跑；**未验证**＝代码就绪但无证据。

### 4.1 检索与问答链路 —— 已实测

- 本地 `BAAI/bge-small-zh-v1.5`（512 维）→ FAISS `IndexFlatL2`；`rank-bm25` + jieba 词级；RRF（k=60）融合；Embedding 余弦重排。
- `meta.embedding_provider` 决定查询编码器，**旧库与新默认值解耦**（切换默认值不会打坏老库）。
- 问答带「资料 + 章节 + 页码」来源前缀；命中真实图内事实（交接记录中的 `ZETA-8642`）已验证。
- 真实 API 最小连通性：DeepSeek `deepseek-chat` 普通问答 1.5s、`chat_with_tools` 1.7s（289+40 tokens），**未更换供应商**。

### 4.2 导入与解析 —— 已实测（含真实教材切片）

- 支持 512MB 单文件流式落盘（4MB 分块），超限/断连/空文件的半成品**创建即登记**、必删。
- 扫描件分流：无文本层 → 本地 RapidOCR 3.x 逐页 OCR（自带 32MB ONNX，离线），引擎降级链 `rapidocr → liteparse → pytesseract`，全缺则显式报错。
- 页级缓存（文件 SHA + 引擎 + DPI）、断点续跑、并发默认 2 上限 3（线程本地引擎，每页独立开 PDF）。
- 阅读顺序：x 方向占用直方图做栏间距聚类，判不出多栏则**原样返回**（不乱猜）。
- 章节：文本层 PDF 走 TOC + 字号；扫描件走 OCR 行正则（**两路，不是三路都会命中**）。
- 真实切片：24 页 / 33.6MB，**24/24 页有文字，134.8s（5.6s/页），0 空白 0 失败**；章节识别正确；检索抽查 3 查询各命中 3 条。

### 4.3 上下文与 Agent —— 已实测（LLM/检索 mock，提示词为真实生产组装）

- 历史预算：`min(0.35×窗口, 131072)`，最近 60% / 摘要 40%，摘要撞 95% 裁半句。
- **请求总预算**（这轮核心）：先扣输出预留，再按「工具描述 → 整项工具 → 工具结果内容 → RAG → 历史 → 摘要」压缩。
- 安全红线：**不裁当前问题、不裁系统提示、不截断工具 JSON/schema/名称/必需参数、不破坏 `tool_call`/`tool_result` 配对**；压到极限仍超窗则返回 `too_long` 明确提示，**不发送被裁坏的请求**。三链路（chat 非流式 / chat 流式 / tutor）共用一套 `fit_request`。
- 实测占用：chat 16000/32068、流式 16955/32068、tutor 30668/31744；40 轮中文长对话仅 8887 token（窗口 27%），当前问题只出现 1 次，学科不串台。
- `MAX_TOOL_RESULT_CHARS=12000` 只是字符辅助上限，**token 份额（25%）才是主口径**。

### 4.4 学习闭环与教师端 —— 已实测（人工验收清单在 `docs/ACCEPTANCE.md`）

- 知识点归属 → 作答 → 掌握度 → 错题 → 复习任务 → Agent，全链路按**每题自身**归属；不可靠归属标「待确认」且不计入精确掌握。
- 计划预算：生效前校验每日预算与教师固定截止，不可行方案保持 DRAFT；确认时复核约束，变化则拒绝旧方案（409）。
- 教师端：课程/班级/教案版本/作业/学情 analytics 全部 200；学生访问 `/api/teacher/*` → 403。
- 角色：`ADMIN_USERS` > `TEACHER_USERS` > 数据库角色，登录返回**有效角色**。

### 4.5 语音与多模态识图 —— 已实测

- 本地 FunASR `paraformer-zh` + `fsmn-vad` + `ct-punc`，独立进程 `:8100`，模型在仓库外。

## 八、下一步建议（按性价比排序）

1. **补效果评测**（对应风险 1、2）：拿 20–30 道真实课程题跑一遍，记录命中率、引用准确率、P95 延迟、单次成本。这是目前唯一「不写代码也能推进、且能对外说话」的事。
2. **前端展示 OCR 限制**（对应风险 5）：把 `job.warnings` 在导入结果面板里显示出来，做一次浏览器实查截图存档。工作量小、用户感知强。
3. **挑一门课重建索引并做前后对比**（对应风险 3）：先备份，再重建，用同一组 query 比命中与排序，确认新章节/页码前缀真的改善检索。
4. **真实双栏教材验证**（对应风险 4）：找 3–5 页真实双栏扫描页，人工核对阅读顺序，决定是否需要继续调聚类参数。
5. **清理技术债**（对应风险 8、9、11）：`ModelSelector` 接线或删除；两套视觉实现择一；`PROJECT_STATUS.md` 收敛到本报告口径。
6. 环境清理：分批删 pytest 临时目录（>30 天优先），一次不超过 50 个对象，避免触发环境保护。
