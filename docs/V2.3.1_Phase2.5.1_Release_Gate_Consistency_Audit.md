## 一、Formula Metadata 一致性

### 问题描述
Phase 2.5 报告中发现 formula 文档的 metadata 不一致：
- `metadata["type"] = "formula"` ✅
- `metadata["modality"] = "text"` ❌ (预期应为 `"formula"`)

### 根因分析
`MultimodalEnricher._enrich_text_document()` 方法中硬编码了 `modality = "text"`，未检查文档是否已有 `type=formula`。

### 修复方案
修改 `rag/enrichment/multimodal_enricher.py` 的 `_enrich_text_document` 方法：

```python
def _enrich_text_document(self, doc: Any) -> Any:
    # 如果已有modality字段（如formula），保留它
    if "modality" not in doc.metadata:
        # 根据type字段决定modality
        doc_type = doc.metadata.get("type", "text")
        if doc_type == "formula":
            doc.metadata["modality"] = "formula"
        else:
            doc.metadata["modality"] = "text"
    return doc
```

### 验证结果
- FormulaAdapter 输出: `type=formula, modality=formula` ✅
- 实际 PDF 加载: 570 个 formula 文档全部具有 `modality=formula` ✅
- 全量 pytest: 202 passed, 0 failed ✅
