### 3. 统一 metadata schema

#### 3.1 新的 metadata 结构
所有 Adapter 输出的 LangChain Document 必须包含以下字段：

```python
metadata = {
    'type': xxx,      # 元素类型
    'modality': xxx,  # 模态类型（与 type 一致）
    'page': xxx,      # 页码
    'bbox': xxx,      # 边界框
    'confidence': xxx, # 置信度
    # 其他原有字段...
}
```

#### 3.2 各类型 metadata 映射

| 元素类型 | type | modality | 特殊字段 |
|---------|------|----------|----------|
| 文本 | text | text | - |
| 图片 | image | image | image_path（如果存在） |
| 公式 | formula | formula | - |
| 表格 | table | table | - |

### 4. 数据流变化

#### 4.1 原有数据流
```
PDFElement → DocumentAdapter → Document
                               metadata: {type: 'text', page: 0, ...}
```

#### 4.2 新数据流
```
PDFElement → DocumentAdapter → Document
                               metadata: {
                                   type: 'text',
                                   modality: 'text',  # 新增
                                   page: 0,
                                   ...
                               }
```

#### 4.3 图片元素特殊处理
**输入**：
```python
PDFElement(
    type=ElementType.IMAGE,
    content={
        'width': 100,
        'height': 80,
        'xref': 123,
        'image_path': '/path/to/image.png'  # 来自 ImageExtractor
    }
)
```

**输出**：
```python
Document(
    page_content="[图片] 尺寸: 100x80, xref: 123",
    metadata={
        'type': 'image',
        'modality': 'image',
        'page': 0,
        'bbox': [...],
        'confidence': 1.0,
        'image_width': 100,
        'image_height': 80,
        'image_xref': 123,
        'image_path': '/path/to/image.png'  # 新增字段
    }
)
```
