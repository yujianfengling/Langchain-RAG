# 独立评测数据导入

使用赛题规定的同一课程范围和字段口径。将新的《课程要求》《题目与材料》《测验节点》《模拟学生》《作答记录》五张 CSV 放在同一目录。课程标准及教材切片沿用同一版本。若更换教材版本，需另行核对页码映射。

在仓库根目录运行，输出路径选择仓库外且尚未存在的目录。

```powershell
.\venv\Scripts\python.exe competition_pipeline/import_dataset.py --csv-dir "评测 CSV 的目录" --out "独立评测输出目录"
```

脚本校验字段并重算正式分析，生成 `bundle`、`analysis-source` 和 `deliverable`。输入表不写回，缺表或字段不兼容时会退出并指出原因。可以用以下命令核对成果包。

```powershell
.\venv\Scripts\python.exe competition_pipeline/export_package.py verify --pkg "独立评测输出目录/deliverable" --src "独立评测输出目录/analysis-source"
```

用**独立端口和独立运行数据目录**启动，便于把评测跟进记录、教师账号和官方样例隔开。新实例先按项目的教师账号流程开通独立评测账号，再用浏览器登录。页顶显示「独立评测数据」。

```powershell
$env:EDU_DATA_DIR = "独立评测输出目录/runtime"
.\start_teacher_redesign.ps1 -Port 8337 -BundleDir "独立评测输出目录/bundle" -SourceDir "独立评测输出目录/analysis-source" -ResourceDir "赛方教材切片目录"
```

下次换包使用新的输出目录和端口，或在独立浏览器配置中打开新实例，以隔离浏览器里保存的现场练习。

## 换包后核对教学助手

在「考试分析」选定班级和测验，然后从顶栏打开「AI 助手」。核对助手顶部的班级和测验，再问「这个班这次测验哪道题失分人数最多？有几人失分？班级得分率是多少？」。班级得分率按有效得分合计除以对应满分合计。单题失分人数按该题有效作答中低于满分的学生去重，与逐题明细的「失分人数」列核对。换包后请重新选择范围并开始新对话。

成果包中的「有效零分」表示存在有效已评分的作答且得分为零。考点级判断仍要求达到有效记录数门槛，未达到时标记为「记录不足」。同题对比按《课程要求》的正式指标生成并校验。
